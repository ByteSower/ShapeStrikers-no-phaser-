# Security Policy

## Supported Versions

The latest code on `main` is the supported version.

## Reporting a Vulnerability

Use the repository's [Report a vulnerability](https://github.com/ByteSower/ShapeStrikers-no-phaser-/security/advisories/new) flow. GitHub private vulnerability reporting is enabled. Do not report vulnerabilities in public issues, discussions, or chat.

Include the affected commit or version, impact, reproduction steps, and relevant browser/device details. Sanitize logs and screenshots; never include credentials, tokens, personal information, or other players' data.

If private reporting is unavailable, open a public issue asking for a private contact channel only. Do not include vulnerability details in that issue.

## Scope and Testing

Reports about security defects in this repository's code and the shipped game are in scope. Do not probe the live site, Supabase project, other users, or third-party services without explicit authorization. Do not attempt denial of service, social engineering, or access to anyone else's data.

## Response and Disclosure

The maintainer will make a reasonable effort to investigate reports and coordinate remediation and disclosure with the reporter. Please avoid public disclosure until a fix or disclosure plan has been agreed. Response and remediation timelines are not guaranteed.

Researchers may request attribution; no identifying information will be published without their consent.
